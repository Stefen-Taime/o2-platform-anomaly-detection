# O2 Platform — Real-Time Anomaly Detection

Real-time anomaly detection on banking transactions and insurance claims.
Inspired by Coinbase's O2 architecture: **Logic-on-Write**, **Logical Clocks**, **In-Memory Processing**.

Targets: BNC, Intact Financial Data Lab, CDPQ.

## Prerequisites

### Local Tools
```bash
terraform --version    # >= 1.5
aws --version          # CLI v2, configured with credentials (us-east-1)
kubectl version        # >= 1.28
go version             # >= 1.21
docker --version       # For building ECR images
```

### External Accounts
- **AWS**: `aws configure` completed (region: us-east-1), IAM permissions (EKS, EC2, DynamoDB, S3, IAM, SNS, Lambda, ECR)
- **Databricks**: Community Edition account (https://community.cloud.databricks.com)
- **Snowflake**: Account with ACCOUNTADMIN role

## Deployment

### Option A: Automated script
```bash
./scripts/deploy.sh
```
This script performs all the steps below automatically.

### Option B: Step by step

#### 1. Generate SSH key
```bash
ssh-keygen -t ed25519 -f terraform/o2-key -N ""
```

#### 2. AWS Infrastructure (Terraform)
```bash
cd terraform
terraform init -upgrade
terraform plan -out=tfplan
terraform apply tfplan
```
Provisions: VPC, EKS (3 nodes t3.medium), DynamoDB, 2x EC2 (MLflow + Jenkins), 2x S3, SNS+Lambda, IAM, Snowflake.

#### 3. Configure kubectl
```bash
aws eks update-kubeconfig --name o2-platform --region us-east-1
```

#### 4. Install Strimzi + deploy Kafka
```bash
./k8s/strimzi-install.sh
kubectl apply -f k8s/kafka-cluster.yaml
kubectl wait kafka/o2-kafka --for=condition=Ready --timeout=600s -n kafka
kubectl apply -f k8s/kafka-topics.yaml
```

#### 5. Build and deploy ECR images
```bash
ECR_URL=$(terraform -chdir=terraform output -raw ecr_repository_url)
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin $ECR_URL

# Kafka Streams App
cd kafka-streams-app
docker build --platform linux/amd64 -t o2-anomaly-detector:latest .
docker tag o2-anomaly-detector:latest $ECR_URL:v2-glibc
docker push $ECR_URL:v2-glibc

# Kafka Connect S3 Sink
cd ../kafka-connect-s3
docker build --platform linux/amd64 -t o2-kafka-connect:latest .
docker tag o2-kafka-connect:latest ${ECR_URL%/*}/o2-platform/kafka-connect-s3:v2
docker push ${ECR_URL%/*}/o2-platform/kafka-connect-s3:v2
```

#### 6. Deploy applications on EKS
```bash
kubectl apply -f k8s/kafka-streams-app.yaml
kubectl apply -f k8s/kafka-connect-s3.yaml
kubectl apply -f k8s/kafka-ui.yaml
```

#### 7. Launch Go generator (local)
```bash
cd generator
go build -o /tmp/o2-generator .

# Port-forward (2 terminals)
kubectl port-forward svc/o2-kafka-kafka-external-bootstrap 9094:9094 -n kafka &
kubectl port-forward svc/o2-kafka-o2-pool-0 31095:9094 -n kafka &

# Launch the generator
/tmp/o2-generator -bootstrap localhost:9094 -rate 100
```

#### 8. Configure Snowflake
```bash
# Run the DDL scripts
snowsql -a <ACCOUNT> -u <USER> -r ACCOUNTADMIN -f snowflake/ddl.sql
snowsql -a <ACCOUNT> -u <USER> -r ACCOUNTADMIN -f snowflake/snowpipe.sql

# Configure SQS notifications on the S3 audit-trail bucket
# (see snowpipe.sql for the SQS ARNs of each pipe)
```

#### 9. ML Training (Databricks CE)
1. Import `databricks/notebooks/01_feature_engineering.py` into Databricks CE
2. Import `databricks/notebooks/02_xgboost_training.py`
3. Run 01 then 02 (features are saved to S3 between the two)

#### 10. Jenkins Blue-Green Pipeline
```bash
# Configure Jenkins credentials (http://<JENKINS_IP>:8080)
# - ARTIFACTS_BUCKET: <from terraform output>
# - MLFLOW_TRACKING_URI: http://<MLFLOW_PRIVATE_IP>:5000
# - SLACK_WEBHOOK: <your Slack webhook URL>

# Create the "o2-blue-green-deploy" job with the contents of jenkins/Jenkinsfile
# Launch the build
```

## Verification

```bash
# Kafka Streams logs (detected anomalies)
kubectl logs -f deployment/o2-anomaly-detector -n kafka

# Read the anomalies topic
kubectl exec -it o2-kafka-o2-pool-0 -n kafka -- \
  bin/kafka-console-consumer.sh --bootstrap-server localhost:9092 --topic anomalies --from-beginning

# MLflow UI
open http://<MLFLOW_IP>:5000

# Jenkins UI
open http://<JENKINS_IP>:8080

# Data in Snowflake
snowsql -a <ACCOUNT> -u <USER> -r ACCOUNTADMIN -q "
  SELECT 'TRANSACTIONS' AS tbl, COUNT(*) FROM O2_PLATFORM.RAW.TRANSACTIONS
  UNION ALL SELECT 'ANOMALY_SCORES', COUNT(*) FROM O2_PLATFORM.RAW.ANOMALY_SCORES;
"
```

## Teardown

```bash
./scripts/teardown.sh
# Or manually:
kubectl delete -f k8s/ --all -n kafka
cd terraform && terraform destroy -auto-approve
```
